# Movie-Industry-Performance-Dashboard

Project Overview

This project analyzes movie industry data using Microsoft Power BI to understand box-office performance, genre trends, movie ratings, and yearly revenue patterns.

Objectives

- Analyze revenue by movie genre.
- Identify top-performing movies.
- Explore yearly box-office revenue trends.
- Compare movie ratings and audience reception.
- Analyze actor and director performance where data is available.
- Present insights through interactive Power BI visualizations.

Tools and Technologies

- Microsoft Power BI Desktop — dashboard creation and visualization.
- Power Query — data cleaning and transformation.
- DAX — calculations and measures, where required.
- CSV — storage of raw and cleaned datasets.

Project Structure

- "01_Raw_Data/" — original movie dataset.
- "clean_data/" — cleaned movie dataset ("cleaned_movie_dataset.csv").
- "Movie-Industry-Performance-Dashboard/" — Power BI report file (".pbix") and related project files.
- "README.md" — project overview and documentation.

Project Workflow

1. Import the movie dataset into Power BI.
2. Clean and transform the data using Power Query.
3. Apply the changes using Close & Apply.
4. Create charts, KPI cards, and interactive filters.
5. Analyze movie revenue, genre performance, ratings, and yearly trends.
6. Save the dashboard as a Power BI ".pbix" file.
7. Export the cleaned dataset as a CSV file and upload the project files to GitHub.

Power BI Dashboard

The Power BI report is provided as a ".pbix" file in the "Movie-Industry-Performance-Dashboard/" folder.

To view the dashboard, download the ".pbix" file and open it using Microsoft Power BI Desktop.

Expected Outcomes

The dashboard provides insights into movie industry performance, including box-office revenue trends, genre comparisons, top-performing movies, and other patterns supported by the available dataset.
