# Movie-Industry-Performance-Dashboard


## Project Overview
This project analyzes movie industry data to understand box-office performance, genre trends, movie ratings, and yearly revenue patterns.

## Objectives
- Analyze revenue by movie genre.
- Study yearly revenue trends.
- Explore movie rating patterns.
- Identify top-performing actors and directors using available data.
- Present findings through an interactive Power BI dashboard.

## Technologies
- Python
- Pandas
- Microsoft Power BI
- Matplotlib (optional for exploratory visualization)

## Project Workflow
1. Data Collection
2. Data Preprocessing
3. Data Analysis
4. Data Visualization
5. Dashboard and Insights

## Team Responsibilities
- **Team Member 1:** Python, data cleaning, and analysis.
- **Team Member 2:** Power BI dashboard and visualizations.

## Project Structure
- `01_Raw_Data/` — Original dataset
- `02_Cleaned_Data/` — Cleaned dataset
- `03_Python/` — Python notebooks and scripts
- `04_PowerBI/` — Power BI report
- `05_Images/` — Screenshots and diagrams
- `06_Documentation/` — Project report and references

## Expected Outcome
An interactive dashboard that presents meaningful insights into movie performance and industry trends.
